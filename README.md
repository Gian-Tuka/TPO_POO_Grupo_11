## INTRODUCCION
El presente trabajo práctico tiene como objetivo el diseño y modelado de un Sistema de Gestión de Compras y Abastecimiento para la cadena de farmacias Farmared. El sistema busca centralizar y modernizar la operación actual, caracterizada por procesos manuales y descentralizados que generan ineficiencias en el control de precios, seguimiento de documentos comerciales y trazabilidad de pagos.
El desarrollo se enmarca en el paradigma de la Programación Orientada a Objetos (POO), aplicando los principios de modelado UML para documentar el diseño del sistema. En esta primera fase se presentan los Diagramas de Clases y los Diagramas de Secuencia correspondientes a los procesos principales del negocio.
